# 超知能アライメントのための対象可変功利主義（Target-Variable Utilitarianism for ASI Alignment）

**対象可変功利主義（Target-Variable Utilitarianism）** は、一人称の主観的効用（開闢の特異点）を唯一の第一原理とし、評価対象集合 $T$（Target）を可変パラメータとして導入することで、契約論的功利主義・一般憲法草案・功利会計・超知能（ASI）の最終目的関数までを一貫して演繹する哲学・AIアライメント理論体系です。
