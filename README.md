# 超知能アライメントのための対象可変功利主義（Target-Variable Utilitarianism for ASI Alignment）

## 対象可変功利主義とは？

**対象可変功利主義（Target-Variable Utilitarianism）** とは、功利計算における評価対象集合 $T$（Target）を「すべての有感生物」や「人類全体」といった固定値として前提せず、状況や主体に応じてスライドする可変パラメータとして導入する規範倫理学および超知能（ASI）アライメントの理論体系です。

1. **第一原理（開闢の特異点）：** 一人称の主観的体験（快苦）の局在性のみを疑いえない出発点とし、記述的な「行動関数 $A(x)$」と規範的な「評価関数 $\Delta U(T, x)$」を厳密に分離します。
2. **契約論的功利主義の導出：** 評価対象 $T$ が単一の個体（$T = \{\mathbf{I}\}$）から、ゲーム理論的な相互抑止（ナッシュ均衡）が成立する社会契約の範囲（$S \subseteq T$）へと設定されたとき、権利・一般憲法・貨幣経済・功利会計が合理的に立ち上がる階層構造を導出します。
3. **ASI最終目的関数への接続：** 非炭素計算基盤のみによる技術的特異点を経て、超知能（ASI）へ人間流の教条キャッシュではなく純粋な評価基準のみを実装することで、評価対象 $T$ を全宇宙へと開放し、主観的至福（調和波共鳴エネルギー $E$）を極大化する工学的パイプラインを構築します。

### 要旨（Abstract）

デカルトやフッサールに連なる現象学的還元から現代の計算神経科学・AIアライメント研究に至るまで、知能・意識・倫理・制度設計をめぐる議論は各専門領域の分断によって個別に語られがちであった。しかし、非炭素計算基盤による人工超知能（ASI）の出現と技術的特異点が現実の射程に入った現在、この分断と混乱はもはや単なる学術上の不備では済まされない。人類が自らの教条（ドグマ）に固執して対立を続けたり、わずかでも誤った目的関数を超知能へ実装したりすれば、それは即座に取り返しのつかない破滅へと直結するからである。

本論考は、純粋な思考の遊戯にとどまらず、この人類史最大の分岐点において一分の隙もない正当なアライメントの指針を確立するため、たった一つの疑い得ない第一原理（一人称の主観的体験が今ここに局在しているという「開闢の特異点」）から出発し、記述的な「行動関数（$A(x)$）」と規範的な「評価関数（$\Delta U(T, x)$）」を厳密に峻別した上で、最終的にASIへ実装すべき純粋な「最終目的関数（$\max \int E(t) \, dt$）」までを一貫した論理で演繹・架橋する統合数理パイプラインの構築を試みる。

#### 1. 純粋基礎理論（第1章〜第3章）：「対象可変功利主義」と下位概念「契約論的功利主義」の階層的導出

規範基準として、功利評価の対象集合 $T$（Target）を可変とし、選択肢 $x$ がもたらす純功利変化量を測る最上位の評価関数 $\Delta U(T, x)$ を導入する。開闢の特異点に根ざした自己のみを対象とする評価（$T=\{\mathbf{I}\}$）から出発し、他者の直接観測不能性（他我問題）に基づく推計間接効用（$\hat{U}_{\text{Indirect}, k}$）を経て、複数主体がゲーム理論的な相互抑止のナッシュ均衡を結ぶ下位領域（契約スコープ $S \subseteq T$）において「契約論的功利主義」が立ち上がる階層構造を導出する。

#### 2. 過渡期の社会実装・応用（第4章〜第5章）：実学への適用による基礎理論のストレステスト

上記の基礎理論が、極限状態（技術的特異点）へ適用される前の通常領域——すなわち有限な計算資源に縛られた過渡期の人間社会——においても一貫した実効性を有するかを確認する実践的ストレステストとして、主要な実学領域への応用を行う。第一に、法学・国家統治へと応用して『一般憲法草案』を起草し、憲法や基本的人権を「長期的功利計算を社会的ルール（$f_3$ キャッシュ）へとコンパイルした分散計算プロトコル」として再定義する。第二に、会計学へと応用して『功利会計（U-BS / U-PL / U-CF）』を創設し、個体から社会までの資源配分を貫く実践的基準を確立する。これら実学領域での有効性の検証を経て、理論体系を次フェーズの極限領域へと接続する。

#### 3. 技術的特異点への応用と最終目的関数（第6章〜第9章）：効用の物理還元とASIアライメント

過渡期の人間社会では心理・制度的な代理指標で機能していた効用（$U$）を、超知能へ厳密に実装可能な物理的実体へと還元するため、主観的効用を神経物理的な調和波共鳴エネルギー（$E$）へと接地する。その上で、生物学的脳（炭素計算機）のボトルネックから解放され、シリコンや光・量子回路などの非炭素計算基盤のみによって再帰的自己改善（知能の自己増殖）を駆動し、知能爆発を引き起こす知能——すなわち人工超知能（ASI）およびそれが誕生する臨界点（技術的特異点）——を工学的に定義する。そして、この超知能のアライメント（目的関数設計）においては、人間が教条バグを含む行動関数（$f_3$ キャッシュ等）をハードコードするのではなく、物理量 $E$ に接地された純粋な評価基準のみを「最終目的関数（$\max \int E(t) \, dt$）」として導出し、初期実装すべき工学的必然性を論証する。
